# 보스 4스킬 · 쿨타임 HUD 설계안 (2026-11-02, 결정 반영 2026-11-03)

사용자 결정(2026-11-02):
- 변신 중 스킬은 4개: 일반(사격), 특수(특수 버튼), 대시(대시 버튼), 기가(기가 버튼).
- 기가어택 비용은 **쿨타임만**(게이지 없음).
- HUD: 왼쪽 아래 아이콘 4개, 쿨타임은 **아이콘 테두리 게이지**로 표시.
- 하향은 나중에. 아래 수치는 시작값이다.
- (2026-11-03) 기가는 8명 모두 **A안**. 변신 직후 기가 바로 사용 가능(쓰면 1200f 쿨타임). 변신하지 않았을 때 HUD는 숨김.

## 2. HUD (아이콘 + 테두리 게이지)

- 그리기: 링 메뉴처럼 투사체 객체 4개를 쓴다. 매 프레임 카메라 기준 왼쪽 아래로 옮긴다.
  - 먼저 할 일: PC판 카메라 좌표 찾기(`FUN_023BC5D0`, `0x041D8E58` 디컴파일, 또는 W+0x28 음수 시험).
  - `proj_frame`의 화면 밖 숨김(`axl_proj.c:409-412`)을 HUD 객체는 건너뛴다. 투사체 풀 48개 중 4개를 계속 쓴다.
- 그림: 아이콘 = 각 스킬의 보스 탄 그림 축소 또는 새 아이콘. 테두리 게이지 = 테두리가 시계 방향으로 차는 그림 N단계(예: 16단계).
  - FX 그림 칸(256)이 꽉 차 있어서 **새 PAT 구간과 텍스처**를 붙여야 한다(선례: 보스 외형 32~39, FX 40). 1~2일.
  - 준비되면 테두리가 다 차고 밝게 한 번 깜빡인다. 쿨타임 중엔 아이콘을 어둡게(팔레트 명암, 링 메뉴 방식).
- 변신하지 않았을 때는 숨긴다(결정 2026-11-03).

### 2.1 구현 (2026-11-03, `lc2/axl_hud.c`, `tools/lc2_dna.py` hud_*)

- 화면 좌표: 객체의 좌표계 바이트 W+0x28을 음수(0xFF)로 두면 게임이 x/y를 화면 픽셀(320x240)로 쓴다
  (`FUN_023bc5d0`·`FUN_023bbad0` 디컴파일: 좌표계 < 0이면 화면 레이어 스크롤을 빼지 않음). 카메라를 따라갈 필요가 없어
  떨림이 없다. e2e에서 카메라가 움직여도 버튼 자리 그대로(아래 그림 f08475, f08633).
  - (참고) 레이어 스크롤: `*(0x041D8CD0) + 0xA0A8 + 0xB4*i`, x +0x14, y +0x1C = 화면 왼쪽 위.
- 배치: 버튼 20x20(아이콘 16 + 테두리 2), 간격 3px, 첫 버튼 중심 (22, 220). 왼쪽 아래, HP 막대(왼쪽 위)와 겹치지 않음.
- 객체: 우리 투사체 4개(`P_HUD`: 이동·애니·게임의 보이기 판정 안 함). X main(`axl_post`, dna_after 뒤)에서 만들고,
  유닛 이동 뒤(`move_hook` → `hud_late`)에 자리·프레임·팔레트·보이기를 정한다. 게임이 지운 경우(스테이지 로드) 다시 만든다.
  X 샷 수에서는 `shot_lent`가 이미 빼 준다(우리 투사체 전부).
- 그림: 새 텍스처 pl02_028(com00 목록 10번)과 PAT 구간 41~48(보스 k = 41 + k - 1). 프레임 = 17 * 칸 + 단계(0~16).
  테두리 부품은 팔레트 층 0, 아이콘은 층 1. 팔레트 3쌍(쿨타임: 아이콘 어둡게 / 준비 / 번쩍: 흰 테두리 6프레임),
  빈 CLUT 자리에 매 프레임 올리고 HUD가 사라지면 원래 값을 돌려 놓는다.
- 아이콘(`HUD_ICONS`): 사격·특수 = 그 보스 탄 그림 축소(울팽 얼음/파편, 히트닉스 초승달/불덩이, 샤크 닻/내려찍기 화살표,
  스크라비치 공/작은 공 3개, 터틀로이드 물방울/껍질 회전 포즈, 셸던 껍질/판, 미지니언 레이 애로(45도)/분신, 얌마크 옵션 탄/잠자리 옵션),
  대시 = 겹화살표, 기가 = 별 모양(보스 색). 보스마다 16색 하나(배경 1 + 기호 3 + 그림 11색 양자화).
- 게이지: 남은 시간 > 직전 값이면 그때 값을 길이로 잡는다(사격 칸은 공격 모션 길이). 단계 = 16 * (길이 - 남음) / 길이.
- 토글: 얌마크 특수(옵션 기차) · 셸던 특수(판) = `dna_alt`, 얌마크 대시 = 빠른 비행 중(`axl_fly_fast`). 켜짐 = 꽉 찬 테두리·밝게, 꺼짐 = 빈 테두리·어둡게.
- 숨김: 변신 안 함, 변신 포즈, 해제 깜빡임, 화면 흰 번쩍임, 링 메뉴, X main이 이번 프레임 돌지 않음(일시정지·아이템 정지),
  컷신(P+0x1EC), 죽음(INIT != 1).
- 시험: `tools/e2e/skill_hud.txt`(값 `hud` = 보이는 버튼 비트), 그림 `docs/visuals/lc2_skill_hud.png`.
